# Nightcap Development MMO

An original, ground-up, solo-capable MMORPG currently in design and discovery.

Repository: [frank-grimes-jr/nightcap-mmo-proto](https://github.com/frank-grimes-jr/nightcap-mmo-proto)

The project aims to recover the danger, mystery, earned competence, memorable towns, and immersive world exploration associated with early online role-playing games while using original intellectual property, modern engineering, accessible quest guidance, and low-spec fully 3D presentation.

## Current status

No technical stack is confirmed and no production implementation has begun. Current work is intentionally focused on product vision, design constraints, visual feasibility, and system interactions.
