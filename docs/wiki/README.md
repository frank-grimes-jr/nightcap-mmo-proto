# Player-Facing Wiki

## Status

Implemented documentation structure, 2026-08-02.

This wiki describes game systems that are coherent enough to explain to players. It is documentation of the current design, not a promise that every described system is final or implemented.

## Reading the wiki

Every page must show one of the project's design statuses: Exploring, Provisional, Confirmed, or Implemented. Details that have not been decided must be labeled TBD rather than inferred.

Canonical decisions remain in `docs/design/decisions.md`. Open design work remains in `docs/design/open-questions.md`. Wiki pages translate those sources into clear player-facing explanations and must be updated when their source decisions change.

## Page convention

Each system page should explain:

- What the system is.
- How players encounter and use it.
- Which risks, rewards, and restrictions players can rely on.
- The page's current design status.
- Which player-visible details remain TBD.
